# Project Overview

Ora's Bakery is a fictional bakery website created as part of the Web Development Portfolio of Evidence (PoE).

The purpose of the website is to promote the bakery's products and services while providing customers with information about the business.

The website is developed using HTML5 only for Part 1 of the project.

---

# Website Goals

The goals of this website are to:

- Promote Ora's Bakery
- Display bakery products
- Provide contact information
- Showcase bakery images
- Allow customers to send enquiries
- Build an online presence
